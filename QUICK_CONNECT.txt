═══════════════════════════════════════════════════════════════
  QUICK DATABASE CONNECTION GUIDE
═══════════════════════════════════════════════════════════════

YOUR CURRENT SETUP:
  MONGODB_URI=mongodb://localhost:27017/attendance_system
  ❌ This won't work - MongoDB is not installed locally

SOLUTION: Use MongoDB Atlas (Cloud - FREE)
  ✅ No installation needed
  ✅ Takes 5 minutes
  ✅ Free forever

═══════════════════════════════════════════════════════════════
  STEP 1: CREATE ACCOUNT
═══════════════════════════════════════════════════════════════

Open in browser:
  https://www.mongodb.com/cloud/atlas/register

Click "Try Free" → Sign up (use Google for faster signup)

═══════════════════════════════════════════════════════════════
  STEP 2: CREATE CLUSTER
═══════════════════════════════════════════════════════════════

1. Click "Build a Database"
2. Select "M0 FREE" (Free tier)
3. Click "Create"
4. Wait 2-3 minutes

═══════════════════════════════════════════════════════════════
  STEP 3: CREATE USER
═══════════════════════════════════════════════════════════════

1. Click "Database Access" (left menu)
2. Click "Add New Database User"
3. Username: attendance_user
4. Password: (create and SAVE it!)
5. Click "Add User"

═══════════════════════════════════════════════════════════════
  STEP 4: ALLOW NETWORK ACCESS
═══════════════════════════════════════════════════════════════

1. Click "Network Access" (left menu)
2. Click "Add IP Address"
3. Click "Allow Access from Anywhere"
4. Click "Confirm"

═══════════════════════════════════════════════════════════════
  STEP 5: GET CONNECTION STRING
═══════════════════════════════════════════════════════════════

1. Click "Database" (left menu)
2. Click "Connect" button
3. Choose "Connect your application"
4. COPY the connection string

It looks like:
  mongodb+srv://attendance_user:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority

═══════════════════════════════════════════════════════════════
  STEP 6: UPDATE .env FILE
═══════════════════════════════════════════════════════════════

Open: backend\.env

Find this line:
  MONGODB_URI=mongodb://localhost:27017/attendance_system

Replace with (ADD /attendance_system before the ?):
  MONGODB_URI=mongodb+srv://attendance_user:YOUR_PASSWORD@cluster0.xxxxx.mongodb.net/attendance_system?retryWrites=true&w=majority

IMPORTANT:
  - Replace YOUR_PASSWORD with your password from Step 3
  - Replace cluster0.xxxxx with your actual cluster
  - Keep /attendance_system (database name)

OR use helper script:
  powershell -ExecutionPolicy Bypass -File UPDATE_ENV.ps1

═══════════════════════════════════════════════════════════════
  STEP 7: RESTART BACKEND
═══════════════════════════════════════════════════════════════

1. Go to backend PowerShell window
2. Press Ctrl+C to stop
3. Run: npm run dev
4. Should see: ✅ Connected to MongoDB

═══════════════════════════════════════════════════════════════
  STEP 8: TEST
═══════════════════════════════════════════════════════════════

Go to http://localhost:3000
Try registration - it should work! 🎉
