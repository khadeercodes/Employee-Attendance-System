# 👀 How to View Your Repository on GitHub

## After Creating the Repository

### Method 1: Direct URL
Once you create the repository, you can access it at:
```
https://github.com/khadeercodes/employee-attendance-system
```

### Method 2: From GitHub Homepage
1. Go to: **https://github.com**
2. Sign in with your account (`khadeercodes`)
3. Click on your **profile picture** (top right)
4. Click **"Your repositories"**
5. Find **"employee-attendance-system"** in the list
6. Click on it to view

### Method 3: Search
1. Go to: **https://github.com**
2. In the search bar (top), type: `employee-attendance-system`
3. Filter by: **Repositories**
4. Click on your repository

- **Actions** tab - CI/CD workflows

## Quick Check Commands

### Check if Remote is Set:
```powershell

```

### View Repository URL:
```powershell
git remote get-url origin
```

### Open in Browser (after push):
