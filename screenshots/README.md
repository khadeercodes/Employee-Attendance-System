# Screenshots Directory

This directory contains screenshots of the Employee Attendance System.

## How to Add Screenshots

1. Save your screenshots in this directory with the following names:
   - `login.png` - Login page
   - `register.png` - Registration page
   - `employee-dashboard.png` - Employee dashboard overview
   - `employee-attendance-chart.png` - Employee attendance chart
   - `employee-attendance-details.png` - Employee attendance details
   - `manager-dashboard.png` - Manager dashboard overview
   - `all-employees-attendance.png` - All employees attendance page
   - `team-calendar-view.png` - Team calendar view
   - `attendance-reports.png` - Attendance reports page

2. Supported formats: `.png`, `.jpg`, `.jpeg`

3. Recommended size: 1920x1080 or similar aspect ratio

4. After adding images, commit and push to GitHub:
   ```bash
   git add screenshots/
   git commit -m "Add application screenshots"
   git push origin main
   ```
